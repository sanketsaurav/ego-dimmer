# Privacy Policy

**Effective date:** August 21, 2026

Ego Dimmer is a Chrome extension that limits the extra brightness of HDR media on websites selected by the user. This policy explains the small amount of information the extension handles to provide that feature.

## Summary

Ego Dimmer has no accounts, analytics, advertising, tracking, or developer-operated servers. The extension does not sell user data or send it to the developer. It handles only the current website's domain name and the preferences needed to apply dimming.

## Information Ego Dimmer handles

Ego Dimmer handles:

- The active tab's URL when the user opens the extension popup, used only to extract the website's domain name. The full URL is not stored.
- The domains where the user has enabled or disabled dimming.
- The user's selected dimming intensity: Full SDR or Gentle.

Ego Dimmer does not collect page titles, visit timestamps, page text, images, videos, communications, form entries, keystrokes, personal identifiers, or analytics.

## How the information is used

The current domain is used to show whether dimming is enabled for that website and to scope any permission request to that site. Stored domains and intensity preferences are used only to apply the user's chosen brightness limit on enabled websites.

Ego Dimmer does not use this information for advertising, profiling, creditworthiness, or any purpose unrelated to HDR dimming.

## Storage and transmission

Preferences are stored with `chrome.storage.sync`. Chrome may synchronize these preferences between browsers where the user is signed in. This synchronization is provided by Google and is governed by Google's applicable privacy policies.

Ego Dimmer does not transmit information to the developer or to any developer-operated service. The packaged extension makes no background network requests.

## Sharing and sale

Ego Dimmer does not sell, rent, or share user data with third parties. The developer cannot access data stored in the user's Chrome Sync account.

## User control

Users can enable or disable dimming separately for each website. Disabling a custom website revokes the extension's permission for that site. A disabled domain preference may remain in Chrome Sync so the extension can remember the user's choice. Users can remove Ego Dimmer's stored settings by clearing the extension's data or uninstalling the extension.

## Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes to this policy

If Ego Dimmer's data practices change, this policy and the Chrome Web Store disclosures will be updated before the new practices are introduced.
